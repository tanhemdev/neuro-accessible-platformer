# Neuro-Accessible Learning Platformer

**This project now lives in [NeuroLearner](https://github.com/tanhemdev/neurolearner).**

NeuroLearner is the working version: a learning platformer kids steer with their hand through a webcam (MediaPipe hand tracking in the browser, plus an OpenCV desktop controller), calibrated to each child's range of motion, with keys, touch and single-switch play too.

- **[Play the live demo](https://tanhemdev.github.io/neurolearner/)**
- **[Code, tests and docs](https://github.com/tanhemdev/neurolearner)**

This repository held the early concept write-up and is kept only so old links still work.
